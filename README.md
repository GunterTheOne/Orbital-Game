# Orbital-Game

# 🚀 Spacecraft Orbital Mechanics Demo

An interactive physics demonstration that simulates spacecraft maneuvering and orbiting around various planetary bodies in space.

## ✨ Key Features
- **Real-Time Gravity Simulation:** Visualizes gravitational attraction and orbital paths around planets of varying masses.
- **Orbital Maneuvering:** Play with acceleration, retrograde burns, and Hohmann transfers to change your orbit.
- **Visual Trajectories:** Live flight-path prediction to help visualize apoapsis, periapsis, and escape velocities.
